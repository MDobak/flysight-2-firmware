Firmware

  1. Connect the FlySight to your computer with USB.
  2. Push and hold the button until the FlySight resets and the light turns orange (about 10 seconds).
  3. Upload the FLYSIGHT.TXT file from the FlySight. The website returns APP.SFB for the hardware batch of your FlySight.
  4. If necessary, make a folder with the name FW on the FlySight.
  5. Copy APP.SFB into the FW folder.
  6. Eject the FlySight.
  7. Disconnect the FlySight from the computer. Wait a few seconds while the FlySight resets and installs the firmware.
{{if gt (len .Firmwares) 1}} {{end}}

With the FlySight app, you can also install APP.SFB over Bluetooth (Device > Firmware).

Audio files

This firmware speaks words that the original audio files do not have. Install these audio files with the firmware.

  1. Download the ZIP file and extract it. It has one folder, AUDIO, with {{.AudioN}} sound files.
  2. Copy the AUDIO folder onto the FlySight. Replace the old files.

Android app

The app connects to the FlySight over Bluetooth. Use it to see the live data, change the settings, get your jumps and show them on a chart and a map, and install APP.SFB.

  1. On your Android phone (Android 13 or later), download the app.
  2. Open the file. If Android asks, let your browser install unknown apps.
  3. Install the app. To update it, download and install the new file. Your jumps and settings stay on the phone.
